# NamPS OS — Product Specification

## 1. Vision & Purpose
NamPS OS is a unified operating system for Namangan Presidential School (NamPS), Uzbekistan. It bridges academic operations, student voice, teaching, and guardian engagement into a coherent, modern, and accessible digital workspace.

## 2. Core Modules
1. **Student Workspace**: Today's classes, weekly timetable, pending assignments, submission drawer, gradebook with teacher feedback, workload threshold monitor.
2. **Teacher Workspace**: Assigned courses, daily schedule, session attendance ledger, assignment creator with time estimates and rubrics, student submission queue with scoring and written comments.
3. **Director Oversight**: School-wide performance KPIs, academic grade averages across grades 5–11, attendance rates, anonymous suggestions review and official disposition, school improvement initiatives.
4. **Manager Administration**: Academic structure (terms, classes, courses), user provisioning, timetable management, transactional bulk CSV import/export with dry-run schema validation.
5. **Guardian Portal**: Independent verified relationship view displaying linked child's attendance, GPA, published grades, and upcoming deadlines.
6. **Truly Anonymous Suggestion Subsystem**: Unauthenticated suggestion submission generating a public receipt code and a private secret token; status tracking with official responses; zero author identity stored in database or application logs.
7. **Workload Coordination Calendar**: Aggregates estimated homework times per student cohort; flags conflicting deadlines (>120 mins) to prevent burnout; supports reschedule proposals.
8. **Knowledge Base & Policies**: Searchable repository of student handbooks, IT security rules, assessment guidelines, and laboratory regulations.
9. **Extracurriculars & Clubs**: STEM, Competitive Programming, and MUN clubs; school calendar events with real-time capacity and registration limits.
10. **Facilities & IT Support**: Instant ticketing for classroom smartboard, projector, or hardware maintenance.
